# Установка LETHE ONE 0.7.2

1. Если LETHE уже запущен: отключите VPN и закройте приложение через меню значка возле часов.
2. Запустите **LETHE-Setup-0.7.2-x64.exe** двойным щелчком. Распаковывать ZIP и выполнять команды PowerShell не требуется.
3. Выберите, нужен ли ярлык на рабочем столе, и нажмите **Установить**. Ярлык в меню «Пуск» создаётся всегда.
4. На последней странице оставьте **Запустить LETHE** и нажмите **Готово**.

Установка выполняется для текущего пользователя в `%LOCALAPPDATA%\Programs\LETHE ONE`. Её следует запускать обычным двойным щелчком, без выбора другого администратора. Для включения VPN Windows по-прежнему запросит разрешение на изменение маршрутов.

Существующие настройки, профиль и журналы остаются в `%LOCALAPPDATA%\LETHE-One`. Установщик не изменяет сервер VPS и не создаёт новый профиль. Переносимая копия в прежней папке остаётся на месте; после установки используйте новый ярлык.

Обновление: закройте LETHE и запустите новый установщик. Незнакомую папку с таким же именем установщик не перезаписывает.

Удаление: **Параметры Windows → Приложения → LETHE ONE → Удалить**. Удаляются только файлы установленного приложения и его ярлыки. Профиль, настройки и журналы сохраняются. Функция «Удалить сервер» в деплое — отдельная операция на VPS.

## Предупреждение Windows

Этот установщик пока не подписан сертификатом издателя. Windows может показать предупреждение о неизвестном приложении; Smart App Control или правила организации могут запрещать его запуск. Установщик не отключает защиту Windows, не меняет политику PowerShell и не снимает метки с посторонних файлов. Для публичного выпуска нужна подпись издателя и проверка на чистой Windows. Новая подпись сама по себе не гарантирует отсутствие предупреждений SmartScreen.

В этой сборке установка через стандартный NSIS заменяет ручную распаковку ZIP: библиотеки записываются установщиком вместе с приложением. Нет сценария с просьбой выполнить Unblock-File.

## Проверка сборки

Собран настоящий Windows x64 Setup.exe стандартным NSIS 3.09. Его содержимое извлечено отдельным архиватором и сверено с исходными файлами и SHA256-каталогом. Мастер установки, ярлыки, обновление и удаление на Windows в среде сборки не запускались.

Исходники приложения и установщика входят в установку. Для пересборки установщика нужен NSIS 3.09 или новее: `BUILD.cmd -Installer`, либо `build\Package-Installer.ps1` для упаковки уже собранного приложения.
