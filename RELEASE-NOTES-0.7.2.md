# LETHE ONE 0.7.2 — setup-1

Дата: 15 октября 2026 года.

## Изменения

- Единые настройки SSH/VPS, домена Caddy, IP входа/выхода и параметров клиента с пояснениями.
- Исправлено сохранение настроек, добавлен просмотр строки доступа VPN.
- Исправлены зависимости SSH и диагностика ошибок подключения.
- Убрана блокирующая предварительная Schannel-проверка: подключение проверяется реальным HTTPS-запросом через NaiveProxy и ожидаемым выходным IP.
- Приложение запускается через LETHE.exe без отдельного окна PowerShell.
- Установка и подтверждаемое удаление компонентов сервера через SSH.
- Стандартный NSIS-установщик для текущего пользователя: ярлыки, запись в приложениях Windows, сохранение профиля при обновлении/удалении.

## Проверено

- Собран Windows x64 установщик. Независимое извлечение и SHA256-проверка 114 файлов прошли.
- Упаковка не изменила исполняемые компоненты клиента 0.7.2.
- Владелец проекта подтвердил успешную установку и работу приложения 15.10.2026.
- Локальные результаты проверок исходников сохранены в docs/TEST-RESULTS.txt.

## Практические ограничения

- Исполняемые файлы пока без подписи издателя.
- Полная приёмка на чистой Windows и установка этой версии на чистом VPS ещё не завершены.
- Поддержка сервера ограничена Debian 12/13 и Ubuntu 22.04/24.04 x86-64 с systemd и назначенными публичными IP.

## Файлы

- LETHE-Setup-0.7.2-x64.exe — рекомендуемый способ установки.
- LETHE-ONE-0.7.2-full.zip — полный комплект исходников и собранных компонентов.
- SHA256SUMS.txt — контрольные суммы файлов выпуска.
