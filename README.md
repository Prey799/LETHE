# LETHE ONE

Windows-клиент системного VPN через NaiveProxy/HTTPS и инструменты развёртывания сервера на VPS.

Текущая версия: **0.7.2**, упаковка установщика: **setup-1**. Проект ранее назывался HTTPS Tunnel Lab.

## Установка на Windows

Скачайте **[LETHE-Setup-0.7.2-x64.exe](https://github.com/Prey799/LETHE/releases/download/v0.7.2/LETHE-Setup-0.7.2-x64.exe)** из [выпуска v0.7.2](https://github.com/Prey799/LETHE/releases/tag/v0.7.2).

1. Отключите VPN и полностью закройте предыдущую версию LETHE, включая значок возле часов.
2. Запустите установщик обычным двойным щелчком и нажмите «Установить».
3. Запускайте LETHE через созданный ярлык в меню «Пуск» или на рабочем столе.

Настройки и зашифрованный профиль сохраняются в `%LOCALAPPDATA%\LETHE-One`. Установка выполняется для текущего пользователя. Для включения VPN запрашиваются права администратора. Установщик пока не подписан: Windows может показать предупреждение об неизвестном издателе.

Требуются Windows 10/11 x64 и .NET Framework 4.8. Подробности: [INSTALL-RU.md](INSTALL-RU.md).

## Что входит

- Приложение Windows без отдельного окна консоли, единый раздел настроек и профили подключения.
- Системный VPN через TUN, NaiveProxy и sing-box; проверка реального запроса через прокси перед включением TUN.
- Журналы подключения и диагностика ошибок по этапам.
- Установка, проверка и удаление принадлежащих LETHE компонентов сервера через SSH.
- Стандартный установщик NSIS с ярлыками, обновлением и удалением через настройки Windows.

## Сервер на VPS

Поддерживаются Debian 12/13 и Ubuntu 22.04/24.04, x86-64, systemd. Нужны SSH и root либо sudo без пароля. Домен заранее направляют единственной A-записью на IP входа, без AAAA; TCP 80/443 должны быть доступны. IP входа и выхода должны быть назначены VPS; NAT VPS в этой версии не поддерживается.

В «Настройках» задаются SSH-доступ, домен и IP. Во вкладке «Деплой» доступны проверка, установка и удаление сервера. Установщик загружает зависимости и Caddy с поддержкой NaiveProxy, настраивает HTTPS и службы, проверяет авторизацию, выходной IP и запрет анонимного доступа. DuckDNS-аккаунт и домен приложение не создаёт.

Удаление приложения Windows сохраняет профиль и настройки и не удаляет сервер VPS. «Удалить сервер» — отдельная подтверждаемая операция в разделе «Деплой».

## Состояние версии

15 октября 2026 года владелец проекта подтвердил: установщик выполнил установку, приложение работает. Это текущая рабочая экспериментальная версия. Развёртывание этой версии с нуля на чистом VPS ещё не прошло практическую приёмку. Полный перечень Windows-проверок находится в [docs/INSTALLER-CHECK.md](docs/INSTALLER-CHECK.md) и [docs/WINDOWS-CHECK.md](docs/WINDOWS-CHECK.md).

В комплекте сохранены настройки адресов лабораторного VPS. Для другого сервера задайте свои параметры в приложении. Личные пароли, токены и пользовательские профили не входят в репозиторий; доступ VPN хранится отдельно в профиле Windows.

## Сборка

В Git хранятся исходники, ресурсы и документация. Готовые EXE/DLL распространяются в файлах выпуска. Для сборки скачайте и распакуйте **[LETHE-ONE-0.7.2-full.zip](https://github.com/Prey799/LETHE/releases/download/v0.7.2/LETHE-ONE-0.7.2-full.zip)** — он содержит полный комплект исходников и зависимостей. Затем на Windows x64 выполните:

```bat
BUILD.cmd
```

Для сборки установщика установите NSIS 3.09 или новее и выполните:

```bat
BUILD.cmd -Installer
```

Если вы работаете с git checkout, сначала скопируйте папки `engine/` и `lib/` из полного архива той же версии в корень checkout. `SHA256-FILES.json` — каталог файлов исходного установочного комплекта; он включает и бинарные зависимости.

Исходники: `src/`, `scripts/`, `server/`; упаковка: `build/`; тесты: `tests/`; лицензии компонентов: `licenses/`. История изменений этого выпуска: [RELEASE-NOTES-0.7.2.md](RELEASE-NOTES-0.7.2.md).
