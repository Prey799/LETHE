# Компоненты LETHE ONE 0.6.0

Три сетевых бинарника перенесены из исходного пользовательского проекта без изменений. Их хеши перечислены в корневом SHA256-FILES.json. Изменения приложения не означают авторство или сертификацию сторонних компонентов.

| Компонент | Источник / сведения |
|---|---|
| NaiveProxy | https://github.com/klzgrad/naiveproxy ; исходные NAIVE-LICENSE.txt и NAIVE-USAGE.txt сохранены. В бинарнике найдена строка Chromium 154.0.8037.49; точный тег сборки по одной строке не устанавливался. |
| sing-box 1.14.2 | https://github.com/SagerNet/sing-box/tree/v1.14.2 ; версия и commit af6e64c3b69e6132ebaee0e1a3d24e93903f6709 прочитаны из Go build info. GPL v3 или новее, см. SING-BOX-LICENSE.txt и GPL-3.0.txt. |
| Wintun 0.14.1 AMD64 | https://www.wintun.net/ ; DLL совпадает с официальным подписанным бинарником. Для него действует WINTUN-PREBUILT-LICENSE.txt из ZIP. WINTUN-LICENSE.txt — лицензия исходников. |
| SSH.NET 2026.0.0 | https://github.com/sshnet/SSH.NET ; MIT, SSH-NET-LICENSE.txt. |
| BouncyCastle и вспомогательные библиотеки .NET | Точные версии, пути NuGet и SHA-256 пакетов: ../build/dependencies.lock.json. В этой папке находятся доступные license/notice-файлы и nuspec с метаданными лицензий. |
| Серверный Caddy с forward_proxy | На VPS скачивается https://github.com/klzgrad/forwardproxy/releases/tag/v2.11.7-naive ; серверный бинарник в клиентский архив не включён. |

Перед публичным распространением установщика нужно подготовить полный комплект лицензий, уведомлений и соответствующих исходников для распространяемых бинарников согласно условиям каждого проекта. Данный архив — разработка и проверка предоставленного пользователем проекта, а не законченный публичный дистрибутив с оформленным сопровождением сторонних исходников.
