# Проверка LETHE 0.7.2 на Windows

1. Отключить и закрыть старую версию. Распаковать 0.7.2 отдельно, открыть LETHE.exe. Убедиться, что нет окна PowerShell, CMD или терминала. В заголовке — 0.7.2.
2. Открыть настройки. Проверить три блока, прокрутку и переходы верхними кнопками. Навести курсор на поля и подписи; проверить подсказки, закруглённые поля и кириллицу. Проверить масштаб 100%/150% и доступность кнопки сохранения на небольшом экране.
3. Убедиться, что старые адреса и профиль сохранились. Выбрать общие IP — отдельные поля должны исчезнуть. Выбрать отдельный IP — появиться. После отмены изменения не сохраняются.
4. Переключить SSH пароль/ключ. Виден только соответствующий ввод. Сохранить и повторно открыть окно. Смена адреса/порта должна сбросить доверенный fingerprint.
5. Импортировать тестовый профиль и отменить: старый профиль не должен меняться. Сохранённый профиль открывать только под тем же пользователем Windows; DPAPI в Linux не проверялся.
6. Подключить VPN, подтвердить UAC. Окон Shell не должно быть и при запуске движков/фонового контроллера. Проверить реальный сайт, внешний IP и раздельные счётчики трафика.
7. Отключить VPN. Проверить завершение обоих движков и guardian, возврат маршрута с LETHE-TUN. Повторить подключение/отключение и выход из трея. При ошибке сохранить журнал из LOCALAPPDATA, не удалять state.json вручную.
8. В «Деплое» проверить действующий сервер и SSH-ключ. Существующий сервер блокирует повторную установку. «Удалить сервер» сначала показывает точный план; отмена не отправляет удаление.
9. Реальное удаление впервые проверять на отдельном тестовом VPS. Для нового LETHE проверить службы, сертификаты, собственные nftables-правила, пользователя и отсутствие файлов. Для старого HTTPS Tunnel Lab — также агент, данные устройств, историю и резервные копии. После удаления SSH должен работать.
10. Проверить неверный домен в подтверждении: кнопка удаления неактивна. После изменения серверной конфигурации старый токен удаления должен быть отклонён. Ошибка/незавершённое удаление не должно отображаться как успех.

Автоматические проверки на Windows включены в BUILD.cmd. Они проверяют загрузку SSH/UI-библиотек, скрытый запуск sing-box без изменения сети и режим `LETHE.exe --action status` в отдельном временном каталоге данных. Само выполнение этих Windows-проверок в среде сборки не проводилось.

Дополнительно для 0.7.2: дважды сохранить SSH-данные и профиль, закрыть и открыть настройки. Проверить «ДОСТУП VPN», «Показать», ручной ввод логина/пароля, отмену без изменения сохранённого профиля. Тесты Test-SettingsPersistence.ps1 на Windows используют временную папку и проверяют DPAPI create/update/read.

Для 0.7.2: подключиться к действующему серверу, проверить tcp-probe-complete, naive-proxy-verified и connected; проверить кнопку «Логи» и отображение причины ошибки. Отрицательная проверка: на тестовом профиле неверный пароль не должен приводить к включению TUN.
