# Единые настройки — 0.6.0 r2, 14 октября 2026

Все редактируемые параметры доступны через одну кнопку «Настройки» в главном окне:

- VPN: профиль, адреса, учётные данные и сетевые параметры.
- VPS / SSH: подключение к серверу и параметры установки.
- Окно: поведение системного трея.

В окне «Деплой» оставлены состояние сервера, журнал и кнопки «Проверить VPS», «Установить сервер», «Закрыть». Настройки из него больше не открываются вторым окном. Чтобы изменить параметры, закройте «Деплой», откройте «Настройки» в главном окне, сохраните изменения и снова откройте «Деплой».

Старые настройки используются из той же папки пользователя; повторно вводить их не требуется. Распакуйте архив целиком в отдельную папку и запустите LETHE.exe после закрытия предыдущей версии.

LETHE.exe остаётся прежним: он запускает обновлённые скрипты интерфейса, поэтому пересборка EXE для этого изменения не требуется. Номер версии самого EXE — 0.6.0.0; редакция интерфейса r2 показана в заголовке окна. Сетевые движки, подключение VPN, серверный установщик и способ хранения настроек не изменены.

Проверка обновления: проверены изменения обработчиков кнопок, отсутствие повторного открытия настроек из «Деплоя» и целостность комплекта. Исторические результаты серверных и сетевых проверок выпуска 0.6.0 сохранены в TEST-RESULTS.txt; заново в рамках этой правки они не выполнялись. Графический интерфейс на Windows в этой среде не запускался.
