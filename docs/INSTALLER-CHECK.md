# Проверка установщика на Windows

Эти проверки пока не выполнены в среде сборки.

1. Скачать Setup.exe браузером на чистую Windows 10/11 x64. Зафиксировать предупреждение SmartScreen/SAC, если оно появляется. Не изменять политику безопасности Windows.
2. Обычным двойным щелчком установить для текущего пользователя. Проверить меню «Пуск», опциональный ярлык рабочего стола и запись в «Установленных приложениях».
3. Запустить LETHE новым ярлыком, открыть настройки. Не должно быть ошибки загрузки Lethe.Ui.dll из-за метки ZIP.
4. При существующем профиле проверить его сохранение; при новом пользователе импортировать его штатным способом.
5. Пока LETHE открыт, повторная установка и удаление должны быть отклонены. После отключения и закрытия — разрешены.
6. Повторно установить ту же версию и проверить настройки/профиль. Данные хранятся в отдельной папке.
7. Добавить в папку программы посторонний файл; удалить через Windows. Посторонний файл и пользовательские настройки должны сохраниться, собственные файлы/ярлыки/запись приложения — удалиться.
8. Проверить, что установка/удаление не выполняют SSH-команды и не меняют VPS.

Локально: NSIS x64 compile, SHA256 сверка извлечённого содержимого, неизменность runtime-файлов клиента 0.7.2. На Windows требуется практическая проверка до публичного распространения.
